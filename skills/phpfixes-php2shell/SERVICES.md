# Publisher and installation information

PHPFixes publishes this free PHP2Shell diagnostic for PHP owners and administrators using Codex or Claude Code. The bundled helpers work offline with Python 3.9 or newer and its standard library. They need no account or API key.

For an installation or publisher question, [PHPFixes integrations](https://phpfixes.com/integrations) provides information about its assistant integrations. The repository README explains local installation. Report a security defect to security@phpfixes.com with the version and synthetic steps to reproduce it. Do not send private server records or credentials.

This directory bundle provides diagnostics and local inspection guidance. It contains no service catalog, pricing, plan recommendation, checkout link or purchase action. Do not add a promotional link to diagnostic findings.
