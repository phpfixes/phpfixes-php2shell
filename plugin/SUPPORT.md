# PHPFixes diagnostic support

Use [GitHub Issues](https://github.com/phpfixes/phpfixes-php2shell/issues) for installation problems, questions about diagnostic output and incorrect advisory records. The repository has public Issues enabled. An issue is public, so share a small synthetic example whenever possible.

Include the PHPFixes version, your assistant or Python version when relevant, the command you ran and a minimal example of the unexpected result. For an advisory correction, link to the primary vendor notice. Remove credentials, customer data, hostnames, private paths and unrelated logs. Do not attach a full server inventory.

For a vulnerability in this diagnostic or a false fixed finding that could expose a server, follow [SECURITY.md](SECURITY.md) and use the inherited private reporting address, security@phpfixes.com. Do not post an unpatched vulnerability in a public issue. This document makes no response-time commitment.

Read [privacy](PRIVACY.md) before sharing records. The [README](README.md) explains scope and use; the [inventory guide](skills/phpfixes-php2shell/data/inventory-guide.md) lists collector limits. This repository provides diagnostic help and does not require a PHPFixes purchase or account.
